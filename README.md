# CarRent — Car Rental Application

## 1. Project Overview

CarRent is a mobile car rental application developed with React Native and Firebase. It allows users to search for, book, and publish vehicles in just a few clicks.

**Target Audience:** Young urban professionals and car rental agencies in Morocco.

## 2. Technologies Used

* **Mobile Framework:** React Native (Expo)
* **Backend:** Firebase (Authentication, Realtime Database, Storage)
* **Language:** JavaScript

## 3. Installation Requirements

* Node.js 18 or higher
* npm or yarn
* Expo CLI
* Firebase account (free)

## 4. Running the Application

1. Navigate to the project directory:

```bash
cd G3-CarRent
```

2. Install dependencies:

```bash
npm install
```

3. Start the application:

```bash
npx expo start --web
```

5. On mobile, scan the QR code using the **Expo Go** application.

## 5. Deployment

The application is not currently deployed online. It runs locally through Expo.

Deployment is possible using **EAS Build (Expo Application Services)** to generate an APK for Android or an IPA for iOS.
